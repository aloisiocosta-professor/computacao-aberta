# Missões interdisciplinares

Integram habilidades para resolver um problema e justificar uma decisão. O contato inicial com outra disciplina não certifica seu domínio. Os pré-requisitos devem ser diagnosticados; as missões avançadas não são ponto de partida obrigatório para um iniciante.

| Missão | Problema | Fase | Disciplinas |
|---|---|---|---|
| [M01: Decidir com dados de consumo simulados](m01.md) | Receber uma lista de consumos fictícios, somar valores e decidir se o total atinge um limite. | iniciante | PRG01, MAT02, SWE03 |
| [M02: Construir uma regra lógica e compará-la com um circuito](m02.md) | Uma saída deve ativar quando duas condições forem verdadeiras. Representar a regra no papel e em programa. | apos_pre_requisitos | MAT02, HWD01, PRG01 |
| [M03: Interpretar uma leitura de sensor sem esconder a incerteza](m03.md) | Comparar leituras sintéticas e investigar se uma diferença pode ser explicada pelas hipóteses do modelo. | apos_pre_requisitos | FIS06, MAT07, PRG01, ELE04 |
| [M04: Escolher uma rota e defender a decisão](m04.md) | Representar um mapa pequeno como grafo e comparar rotas sob uma função de custo declarada. | apos_pre_requisitos | ALG04, PRG02, SWE03, PRO01 |
