# Pesquisa exploratória — fundamentos, formação profissional e interação

Data de consulta: 01/11/2026. Escopo editorial: 68 unidades dos eixos FND, PRO e HCI, incluindo os itens de cursos externos vinculados a essas disciplinas. Arquivo: `data/conteudos-fundamentos.json`.

## Método e estado

Busca exploratória em páginas oficiais e documentação primária, com leitura de trechos pertinentes. Não é revisão sistemática, avaliação de eficácia pedagógica ou revisão humana especializada. Os conceitos e cenários são redação autoral introdutória; os exemplos quantitativos e situações são fictícios. As fontes são associadas a seu escopo de uso e não apresentadas como validação integral de cada atividade.

Base/canal: busca web e leitura de páginas públicas oficiais. Consultas literais principais:

- `site.w3.org WAI tutorials accessibility barriers functional requirements`
- `site.git-scm.com/book Recording Changes Repository`
- `site.acm.org code of ethics professional responsibilities`
- `site.pbr-book.org sampling light transport rendering`
- `site.acm.org code ethics 1.2 avoid harm`
- `site.nist.gov research reproducibility documentation reproducible`
- `site.itu.int global e waste monitor 2024 reuse recycling`
- `site.nasa.gov systems engineering verification validation requirements`

Critérios de seleção: domínio oficial da organização ou documentação mantida pelo projeto; correspondência com a ideia introdutória; possibilidade de preservar leitura e acesso parciais. Não foram reproduzidos capítulos ou exercícios externos. Não foram acrescentados subitens aos índices externos.
