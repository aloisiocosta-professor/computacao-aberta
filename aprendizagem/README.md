# Aprender para conseguir fazer e decidir

O objetivo principal é desenvolver habilidades práticas, com evidências e aplicação em outros contextos. A consulta de materiais alimenta esse processo; a conclusão de uma leitura não será tratada como domínio automático.

1. [Começar sem presumir formação prévia](comecar.md).
2. [Encontrar uma habilidade](habilidades.md) ou [ver a cobertura dos índices](cobertura.md).
3. Trabalhar a unidade: previsão, representação, exemplo, prática, feedback e nova tentativa.
4. [Integrar disciplinas em uma missão](../missoes/README.md).
5. [Registrar o desempenho e a retomada](progresso.md).

Quem prefere ler pode usar o texto; quem usa áudio pode narrar ou ouvir um recurso autorizado; as tabelas e diagramas têm alternativa textual. Não é preciso instalar ferramentas para começar com papel e navegador. A oferta de formatos é uma escolha de acessibilidade e desenho da tarefa, não um rótulo fixo de “aprendiz visual”.

Neste projeto, **julgamento prático** significa comparar alternativas, prever consequências, justificar uma decisão e reconhecer quando o próprio conhecimento é insuficiente. É uma definição operacional proposta para aproximar o objetivo de sabedoria prática; não é certificado de sabedoria ou consciência.

Há formatos comuns para humanos e agentes, com [limites de avaliação diferentes](../agentes/PROTOCOLO.md). Executar uma instrução é um desempenho observável, não prova de treinamento permanente de um modelo.
