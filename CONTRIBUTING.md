# Como contribuir

Abra uma issue com problema, fonte primária, versão, escopo e critério de aceite. Para uma disciplina, informe conhecimento, habilidade observável, pré-requisitos, método, atividade, curso e capítulos pertinentes. Não proponha livros apenas pelo título: explique a aderência e o estado de leitura.

Edite data/*.json e execute os dois scripts descritos no README. Envie uma branch feature/descricao a develop; alterações para main passam por revisão. Use Conventional Commits e vincule o PR à issue real. Não invente números de issues. Tags e releases exigem decisão explícita do mantenedor.

Separar correção estrutural de avaliação científica. O CI verifica estrutura; um eixo exige revisão por alguém com domínio da área. Fontes e títulos de terceiros não recebem nossa licença. Não incluir PDFs sem licença e atribuição verificadas. Não inserir credenciais ou dados pessoais de estudantes.

Contribuições originais são oferecidas sob as licenças deste projeto, com preservação de atribuição. Não é exigida transferência de copyright.
